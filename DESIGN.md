# Vortex One PropFlow Design Context

## Direction
Operational intelligence workspace: dark command-center navigation, restrained motion, high information density without dashboard clutter.

## Interaction contract
Interactive controls use native buttons/links, visible focus, stable loading states, and explicit error states. No fake connection toggles.

## Navigation
Organize features by Command Center, Portfolio, Growth, Operations, Automation, Administration. URL-backed module routes are preferred over local-only tab state.

## Signature
A live readiness/integration status layer is the distinctive product element: the system should show what is actually connected, what is partial, and what is blocked.

## Accessibility
Target WCAG 2.2 AA. Respect reduced motion. Preserve keyboard navigation and visible focus.
